# Claude Export Viewer

[English](README.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · **Русский** · [简体中文](README.zh.md)

Полностью локальный просмотрщик экспорта данных, который можно скачать из Claude.ai. Откройте `conversations.json`
или zip-файлы экспорта и читайте свои чаты с ветками, поиском, вложениями, проектами, памятью и артефактами.

Ничего не загружается в сеть: страница использует строгую Content-Security-Policy и не может обращаться к сети.
Неофициальный инструмент, не связанный с Anthropic.

## Возможности

- Читает экспорт как есть: JSON, zip-файлы или распакованную папку. Тип файла определяется по содержимому,
  поэтому переименованные файлы тоже работают.
- Markdown с подсветкой кода, свёрнутыми рассуждениями и вызовами инструментов, вложениями и цитатами.
- Ветки: элемент `< 2 / 3 >` переключает между отредактированными или повторными версиями.
- Полнотекстовый поиск с подсветкой совпадений в чате. Нажмите `/`, чтобы перейти к нему.
- Сортировка по дате, группировка по дате или по проекту.
- Проекты с инструкциями, документами и памятью, а также чаты и артефакты, которые вы к ним отнесёте.
- Чаты без читаемого содержимого попадают в раздел *Пустые чаты* с причиной, прочитанной из файла.
- Экспорт чата, проекта, памяти, артефакта или рефлексии в Markdown, а проекта, всей памяти, всех артефактов или всех рефлексий — в zip.
- Память, артефакты и рефлексии — в отдельных разделах.
- Доступно на английском, испанском, немецком, французском, русском и упрощённом китайском. Язык выбирается
  на стартовой странице или кнопкой языка на боковой панели. Он применяется и к экспортируемому Markdown.

## Быстрый старт

Нужен только Python 3, без сборки и пакетов.

```bash
python serve.py
```

Сервер работает на `http://127.0.0.1:5173` (только localhost) и открывает браузер. В Windows можно запустить
`start.bat`. Параметры: `--port 8080`, `--no-open`.

## Загрузка экспорта

Перетащите файлы или папку на страницу либо нажмите **Выбрать файлы** / **Выбрать папку**. Файлы можно добавлять
в любой момент: они объединяются с уже загруженными.

| Файл | Содержимое |
| --- | --- |
| `conversations.json` | Все чаты. Одного этого файла достаточно |
| `conversations-XXX.zip` | То же самое в zip-архиве |
| `projects-XXX.zip` | Инструкции и документы проектов |
| `memories-XXX.zip` | Глобальная память, память проектов, файлы памяти |
| `frames-XXX.zip` | Артефакты с читаемой страницей |
| `feedback-XXX.zip` | Ежемесячные рефлексии |
| `design_chats-XXX.zip` | Распознаются, но сообщений для них в экспорте нет |

`XXX` — номер части, например `000`.

Иногда Claude присылает только небольшой список `manifest-....json` со ссылками для скачивания. Перетащите его,
и просмотрщик покажет ссылки claude.ai (они никогда не открываются и не сохраняются), чтобы вы могли скачать
zip-файлы. Они действуют 24 часа.

Файлы учётной записи, такие как `users.json` и `login_history.json`, никогда не загружаются.
Отметьте **Хранить загруженный экспорт в этом браузере**, чтобы сохранить его в IndexedDB; кнопка с корзиной или
**Очистить** удаляет его.

## Примечания

- **Проекты:** в экспорте не указано, к какому проекту относился чат или артефакт. Используйте меню **Проект** в чате или артефакте либо
  **Добавить чаты** / **Добавить артефакты** в проекте. Выбор сохраняется только в этом браузере.
- **Пустые чаты:** просмотрщик не может восстановить текст, которого нет в экспорте, и не гадает о причине.
  Причины ограничены тем, что видно в файле, например: нет сообщений, все тексты пусты или есть только заглушка.
- **Конфиденциальность:** нет аналитики, CDN и удалённых шрифтов, библиотеки включены в проект. Удалённые
  изображения не загружаются (отображаются как ссылки `[изображение: alt]`), «сырой» HTML в сообщениях
  экранируется, а ссылки ограничены схемами `http`, `https` и `mailto`. Настройки хранятся в `localStorage`.
- **Браузеры:** актуальные Chrome, Edge, Firefox или Safari.
- **Ограничения:** `conversations.json` размером около 500 МБ и больше нельзя обработать во вкладке.
  Изображений и бинарных вложений в экспорте нет, только их имена.

## Разработка

Обычные ES-модули, без сборщика и без Node.

```
index.html          точка входа и CSP
serve.py            статический сервер на 127.0.0.1
src/lib/            импорт, дерево веток, поиск, экспорт, i18n (без DOM)
src/components/     представления на Preact + htm
src/locales/        переводы: en (эталон), es, de, fr, ru, zh
src/styles.css      оформление
fonts/, vendor/     Medeo Mono, встроенные библиотеки
tests/              набор тестов для браузера
```

Тесты: запустите `python serve.py` и откройте `http://127.0.0.1:5173/tests/`. В заголовке вкладки будет `PASSED n` или `FAILED n`.

Переводы: строки лежат в `src/locales/<код>.js` и читаются через `t()` и `tn()` (множественное число) из
`src/lib/i18n.js`. Чтобы добавить язык, скопируйте `en.js`, переведите файл и зарегистрируйте его в `i18n.js`.
Тесты падают, если в переводе нет ключа или подстановки либо не хватает формы множественного числа, нужной
этому языку. Начальный выбор определяется языком браузера; выбор сохраняется в `localStorage`.

Участие в разработке: создавайте ветки от `main` (`feature/...`, `fix/...`, `docs/...`), используйте
[Conventional Commits](https://www.conventionalcommits.org/) и открывайте pull request с пройденными тестами.
